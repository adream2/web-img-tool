三个真问题，一次解决

同类工具通常只做"列出来"这一步。真正耗时间的是筛、改、存。

01 / 扫

扫得全

DOM、样式表、网络请求三路合并。懒加载、srcset 多倍图、Shadow DOM、iframe、CSS 背景与遮罩图都能抓到；长页面用「深度扫描」自动滚动触发加载。

02 / 筛

筛得准

按尺寸（≥100 / 300 / 600 / 宽 1000 / 宽 1920 / 自定义宽高）、按类型、按关键词包含与排除。支持按宽、高、面积、体积排序，也可以让相似图自动合并。

03 / 出

处理得了

批量打包 ZIP，或逐张下载。改尺寸（56 种预设）、裁剪、压缩、JPG/PNG/WebP 互转、放大、转 Base64，全在本地算完直接落盘。

三步上手

装扩展

在 Edge 加载项商店点「获取」，或下载源码在 edge://extensions 开发者模式下加载。

点工具栏图标或按 Alt+Shift+I，在「图片检测」里点「扫描页面」。长页面点「深度扫描」。

筛完就下

选尺寸、勾图片、点「批量下载」。要改图就切到「图片处理」，改完直接下载。

常见问题

真的不上传我的数据吗？

是。扫描、处理、压缩、转格式全部在本机完成，没有服务器也没有统计。只有你主动点击"上传图床"或"AI 放大"时才会连网，而且地址是你自己填的。

为什么要"访问所有网站"的权限？

图片可能在任何站点上，扩展需要在页面里读取图片地址和样式信息才能列出它们。权限仅用于读取，不修改页面内容、不拦截请求。完整说明见隐私政策。

有些图下载失败是怎么回事？

多数是站点开了防盗链或需要登录。扩展会先尝试带上你的登录态抓取，失败时会明确提示原因（比如"服务器拒绝下载（403）"），不会静默失败。

支持 Chrome 吗？

支持。Chrome / Edge / 其他 Chromium 内核浏览器都能装，同一个包。

收费吗？以后会收费吗？

免费，无内购、无会员墙。源码公开，你可以自己审、自己改。
