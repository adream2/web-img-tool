Web Image Tool Pro 隐私政策

最后更新：2026-11-18 · 适用版本：1.2.0 及以上

一句话说明：本扩展不收集、不上传、不转售任何个人信息或浏览数据。 图片的扫描、处理、压缩与格式转换全部在你的浏览器本地完成。

1. 我们不收集什么

  • 不收集浏览历史、访问的网址、页面内容
  • 不收集图片内容本身，也不回传任何图片
  • 不收集账号、设备标识、位置
  • 无统计埋点、无广告 SDK、无第三方分析服务
  • 没有服务器，扩展不向开发者回传任何数据

2. 数据在哪里处理

动作处理位置是否联网
扫描页面图片你的浏览器内（页面脚本 + Service Worker）否
尺寸探测、相似图比对你的浏览器内（Canvas）否
裁剪 / 缩放 / 压缩 / 转格式 / 放大你的浏览器内（Canvas）否
下载图片你的浏览器下载管理器仅请求图片原始地址
上传到 GitHub 图床你的浏览器 → api.github.com是（仅当你主动点击上传且已配置）
AI 放大你的浏览器 → 你填写的接口地址是（仅当你主动点击放大且已配置）

3. 本地存储的内容

扩展使用浏览器提供的 chrome.storage 保存配置，这些数据留在你的设备上，随浏览器账号同步（若你开启同步）：

键内容位置
defaultFormat / defaultQuality默认输出格式与质量storage.sync
picx*GitHub 图床配置（你自行填写）storage.sync
aiUpscale*第三方 AI 放大接口配置（你自行填写）storage.sync
wit-scan-cache最近一次扫描到的图片地址清单，30 分钟自动过期storage.session

GitHub Token 与 API Key 只用于向对应服务发起请求，不经过任何中间服务器，开发者无法获取。

4. 权限用途

权限用途
activeTab / tabs读取当前标签页标识，用于把扫描结果与标签页对应
全站访问图片可能位于任意网站，需要读取页面中的图片地址与样式信息
scripting在用户点击扫描时向当前页注入扫描脚本
storage保存你的设置与临时扫描缓存
downloads保存你选择下载的图片
contextMenus提供图片右键菜单项
webRequest被动监听图片响应，补齐页面脚本看不到的图片（不修改、不拦截请求）
webNavigation页面跳转时清空上一页缓存，避免混入上一页图片

所有权限仅服务于上述功能，不用于任何形式的数据采集。

5. 第三方服务

只有在你主动配置并触发时，扩展才会与你指定的第三方服务通信：

  • GitHub（api.github.com）：上传图片、读取仓库目录。适用 GitHub 隐私声明。
  • AI 放大接口（地址由你填写）：上送你选择放大的那张图片，返回处理结果。该服务的数据处理行为由其提供方决定，请自行确认其隐私条款。

除上述情况外，扩展不会与任何第三方通信。

6. 数据共享与出售

我们不出售、不出租、不共享任何用户数据。没有数据可供共享——扩展不收集数据。

7. 数据删除

  • 卸载扩展：浏览器会删除该扩展的全部本地存储
  • 只清配置：在扩展「设置」中清空 GitHub / AI 配置，或在浏览器的扩展存储管理中清除
  • 扫描缓存：30 分钟自动过期，关闭浏览器立即清除

8. 儿童隐私

本扩展不面向 13 岁以下儿童设计，也不收集任何年龄相关信息。

9. 政策变更

若未来版本引入需要联网的新功能，我们会在本页面更新说明，并在扩展的版本更新说明中注明。继续使用即表示接受更新后的政策。
